GeoTag Studio 使用说明
======================

项目主页与更新：https://github.com/wumiann/geotag-studio


一、运行
--------
1. 把整个压缩包解压到一个普通文件夹，例如 D:\Tools\GeoTagStudio。
   不要在压缩包里直接运行，也不要放进 C:\Program Files 这类受保护的目录。
2. 双击 GeoTagStudio.exe。

适用于 64 位的 Windows 10 / Windows 11，需要联网加载地图。
压缩包里已经自带 ExifTool，不需要再安装别的软件。
首次运行会在同目录生成 data 文件夹，用来保存你的设置和处理记录。


二、三步上手
------------
1. 添加文件：点“添加照片、RAW 或视频”，或者把文件（也可以是装着它们的文件夹）
   拖到左侧的“待处理文件”区。
2. 选位置，三种方式任选一种：
   - 在地图上点一下，图钉可以拖动微调；
   - 在搜索框里输入地名，按回车，再在结果里点一条；
   - 在搜索框里输入“纬度,经度”。
3. 写入：点右下角的“写入 N 个文件”，核对弹出的清单，点“确认写入”。

写入完成后，成功的文件名右边会标“已处理”，失败的会写明原因。
右上角的“处理记录”可以查看历次结果。
列表里的“×”“清除已处理的”“清除全部”只是把文件从列表里去掉，不会删除任何文件。


三、配置高德地图（推荐）
------------------------
默认使用的 OpenStreetMap 在国内通常需要代理才能加载。推荐免费申请一个高德 Key：

1. 登录高德开放平台 https://console.amap.com/dev/key/app
2. 创建一个应用，点“添加 Key”，服务平台一定选“Web端(JS API)”。
   选成“Web服务”的 Key 不能用来显示地图。
3. 把得到的 Key 和安全密钥填进程序右上角的“⚙ 设置”，点保存。

Key 只保存在你电脑上的 data 文件夹里，不会随程序分发给任何人。
配好之后，地点搜索和处理记录里的“城市”也由高德提供。


四、常见问题
------------
· 提示找不到 exiftool.exe，或者 Could not find ...\perl5*.dll
  压缩包没有完整解压。exiftool.exe 必须和 exiftool_files 文件夹放在一起。

· 地图是空白的
  先检查网络。高德地图加载失败时，地图上方会显示高德返回的错误码，
  多半是 Key 的类型不对，或者安全密钥没填。

· 搜索失败，或者提示连接搜索服务超时
  没有配置高德 Key 时，搜索使用 OpenStreetMap 的服务，在国内同样需要代理。
  配好高德 Key 就会改用高德搜索。

· 写入失败：Not a valid JPG
  文件本身已经损坏，或者扩展名和实际内容不符。

· 多出来的 .bak 文件是什么
  写入前的原始文件备份。确认位置无误后可以手动删除；
  再次写入不会覆盖已有的 .bak。写错了，就把对应的 .bak 改回原来的文件名。

· 原文件会被修改吗
  照片和 RAW 会被修改，所以程序默认先备份。视频不会被修改，
  位置写在旁边的同名 .xmp 文件里。


五、隐私
--------
照片和视频不会被上传，处理全部在本机完成。
联网只用来加载地图、搜索地点和查询城市，内容只有地名和坐标。
